# TCC---Amostragem-complexa
Códigos referentes ao trabalho de conclusão de curso de tema 'Comparação entre planos amostrais complexos equiprováveis e não-equiprováveis'

Os códigos amostra_epsem_tcc.sas e amostra_não_epsem_tcc.sas geram as amostras quase-equiprováveis e não-equiprováveis respectivamente.

O código macros_under_oversized.sas são utilizados para carregar as macros que solucionam os problemas de superdimensionamento e sobredimensionamento da amostragem complexa.
